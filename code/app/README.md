## Описание процесса 

1. Создание локального контейнера: 
   - Сначала был создан Docker контейнер локально на машине разработчика. Этот контейнер включает все необходимые зависимости и настройки для запуска приложения.

2. Создание Streamlit приложения: 
   - В рамках проекта было разработано Streamlit приложение, которое отображает результаты работы по чекпоинту и включает клиентскую часть для взаимодействия с сервером на fastAPI. Настроено логирование с механизмом ротации

3. Тестирование: 
   - После создания контейнера и приложения они были протестированы локально, чтобы убедиться в корректной работе и функциональности.

4. Загрузка в Docker Hub: 
   - После успешного тестирования контейнер был загружен в Docker Hub. Это позволяет другим пользователям легко получить доступ к контейнеру. О том, как взаимодействовать с контейнером описано в report.pdf

## Предварительные требования
- Установленный Docker
- Python
- Streamlit
- Библиотеки, используемые в приложении (в requirements.txt)
